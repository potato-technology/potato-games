# Potato Games

A free browser game hub with 31 games: Tow Rush, Tater Typer, Order Up!, Goblin Gate, Gem Mine, Jungle Dash, Beat Drop, Sunny Acres, Brick Blitz, Putt Party, Snake Arena, Lucky Lake, Shadow Heist, Word Wizard, Star Blaster, Hoop Shot, Pet Pals, Ghost Maze, Puck Blast, Hop Road, Tank Arena, Slice Squad, Merge Mania, Goal Rush, Dungeon Delve, Kart Kings, Bubble Pop, Block Stack, Strike Lanes, Skate Rush and Idle Kingdom.

Play by opening `index.html` through a web server, or on the GitHub Pages site for this repo.

Earn Spuds in any game and spend them on hats, colors and faces for your potato in the Shop. Progress is saved in your browser.
