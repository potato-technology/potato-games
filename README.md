# Potato Games

A free browser game hub with 16 games: Tow Rush, Tater Typer, Order Up!, Goblin Gate, Gem Mine, Jungle Dash, Beat Drop, Sunny Acres, Brick Blitz, Putt Party, Snake Arena, Lucky Lake, Shadow Heist, Word Wizard, Star Blaster and Hoop Shot.

Play by opening `index.html` through a web server, or on the GitHub Pages site for this repo.

Earn Spuds in any game and spend them on hats, colors and faces for your potato in the Shop. Progress is saved in your browser.
