# Potato Games

A free browser game hub with 50 games: Tow Rush, Tater Typer, Order Up!, Goblin Gate, Gem Mine, Jungle Dash, Beat Drop, Sunny Acres, Brick Blitz, Putt Party, Snake Arena, Lucky Lake, Shadow Heist, Word Wizard, Star Blaster, Hoop Shot, Pet Pals, Ghost Maze, Puck Blast, Hop Road, Tank Arena, Slice Squad, Merge Mania, Goal Rush, Dungeon Delve, Kart Kings, Bubble Pop, Block Stack, Strike Lanes, Skate Rush, Idle Kingdom, Toothpaste Pro, Sky Stack, Bullseye, Pinball Party, Board Buddies, Treasure Sweeper, Picture Cross, Lemonade Stand, Moon Lander, Color Sort, Hill Rider, Jet Pup, Tennis Ace, Sky Bounce, Powder Peak, Candy Drop, Sumo Bots, Card Castle and Wave Rider.

Play by opening `index.html` through a web server, or on the GitHub Pages site for this repo.

Earn Spuds in any game and spend them on hats, colors and faces for your potato in the Shop. Progress is saved in your browser.
